# LeetCode 295 步骤设计与验收

## 设计原则

一帧只讲一个用户可见的算法动作，不为凑数量展示无关计算。每次 `addNum` 拆成“新数字到达 → 与左边界比较 → 放入目标堆 → （需要时）上滤交换 → 检查两边数量 → （需要时）移动分界数”。每次 `findMedian` 拆成“确认元素总数 → 确认奇偶与中间位置 → 读取边界并计算”。没有发生的交换/平衡不虚构步骤。

## 默认样例估计

`[1, 2, findMedian, 3, findMedian]` 包含初始化、每次加入的判断/入堆、两次查询、插入 3 后的必要平衡和结束状态。当前每次加入独立显示“到达、比较、放入堆”，每次查询显示“查询开始、奇偶分支和结果”；平衡时展示数量检查、移出边界、放入另一堆、堆序恢复和最终数量状态。最近实现中默认样例为 27 帧；倒序与边界压力样例分别达到 48 / 44 帧。
